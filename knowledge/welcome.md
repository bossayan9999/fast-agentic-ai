# Welcome to the Fast Agentic AI Knowledge Vault

This folder acts as an **Obsidian-style local knowledge base** that is versioned and backed up on GitHub.

## How it works

- The agent searches this folder when memory is needed.
- You can add `.md` notes here (or via the `/api/memory` endpoint).
- Conversation sessions are optionally logged under `knowledge/sessions/`.

## Example

Agentic AI loops typically follow:

1. Intent Analysis
2. Task Planning
3. Tool / Plugin invocation
4. Action Execution
5. Answer Synthesis
6. Feedback Loop

The MCP (Meta-Controller & Planner) coordinates these stages and synthesizes results from local memory + external tools.
